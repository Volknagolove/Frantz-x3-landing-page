# Frantz x3

Русская посадочная страница находится в `ru/index.html`, общие стили — в `style.css`, таймер — в `script.js`. Структура допускает добавление других языковых папок.

Для локального просмотра установите Node.js, затем запустите из корня проекта `npx --yes http-server . -p 8000` и откройте `http://localhost:8000/ru/`. При первом запуске npx скачает пакет http-server.

Перед публикацией:
- Уточнить время и часовой пояс открытия и заменить `OPENING_DATE` в `script.js`; сейчас временно указано 19:00 GMT+2 22 января 2027 года.
- Подтвердить дату ОБТ: сейчас указано 15 января 2027.
- Проверить адрес страницы «Начать играть»: сейчас используется кабинет ElmoreLab.
- Шрифты и фоновые изображения хранятся в папке `assets`. Иконка Telegram загружается из Font Awesome.


Видео: в `script.js` укажите `VIDEO_URL`: обычную ссылку YouTube, TikTok, Instagram или прямую ссылку на файл MP4, WebM либо OGV (в том числе на другом сервере или локальный путь). Если у прямого файла нет расширения в URL, задайте `VIDEO_TYPE = 'direct'`; для остальных ссылок оставьте `'auto'`. Пустой URL скрывает плеер. Автозапуска нет, видео загружается с `preload=metadata`. Сервер должен отдавать сам видеофайл, разрешать доступ и поддерживать выбранный браузером формат; для перемотки желательна поддержка Range-запросов. Не каждая страница или видеосервис разрешает встраивание. Короткие ссылки TikTok сначала разверните до полного адреса с `/video/`.

Формат плеера задаётся через `VIDEO_ORIENTATION` в `script.js`: `auto`, `vertical` или `horizontal`. В режиме `auto` ссылки YouTube Shorts считаются вертикальными, обычные ссылки YouTube — горизонтальными; формат прямого видео определяется по его размерам. Для TikTok и Instagram по умолчанию используется вертикальный формат. Короткая ссылка YouTube не указывает формат ролика: при необходимости задайте его вручную.
